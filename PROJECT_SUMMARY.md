# Project Summary: Jarida Flipbook

## Overview
Transforming a basic flipbook prototype into an authentic "Old Newspaper" digital experience named **Jarida** (جريدة الأفق).

## GitHub Repository
- **URL**: [https://github.com/ab99-c/jarida](https://github.com/ab99-c/jarida)
- **Status**: Renamed from `EL-JAZEERA-`, main branch updated with vintage style and responsive design.

## Vercel Deployments
- **Authentic Version**: [jarida-authentic-2026.vercel.app](https://jarida-authentic-2026-iqbj2dtu3-azizaithaddou877-6369s-projects.vercel.app)
- **Responsive Version**: [jarida-final-responsive.vercel.app](https://jarida-final-responsive-1eycbb3ni.vercel.app)

## Design Identity
- **Style**: "Ath-Thawra" newspaper layout (Syrian newspaper style).
- **Colors**: White/Off-white paper, black ink, blue accents (`#2b7a9e`).
- **Typography**: `Amiri` (Masthead), `Noto Naskh Arabic` (Body), `Tajawal` (UI).
- **Features**: 3D Page flip, multi-device support (PC/Tablet/Mobile), realistic paper textures, and fold shadows.

## Assets Used
- **Logo/Icons**: Inlined SVG or Base64 (from original prototype).
- **Textures**: Paper fibers pattern from transparenttextures.com.
- **Images**: Unsplash placeholders for news content.
